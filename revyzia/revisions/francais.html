✍️ Homophones (pièges de dictée)

a / à : « a » = avoir (→ avait) ; « à » = préposition.
et / est : « est » = être (→ était).
son / sont : « sont » = être (→ étaient).
on / ont : « ont » = avoir (→ avaient).
ce / se : « se » devant un verbe (se laver).
ces / ses : « ses » = les siens (possession).
leur / leurs : « leur » + verbe = invariable ; « leurs » + nom pluriel.
ou / où : « où » = lieu.

🔤 Classes & fonctions

Classes variables : nom, déterminant, adjectif, pronom, verbe.
Classes invariables : adverbe, préposition, conjonction, interjection.
Sujet : « qui est-ce qui ? ». COD : « quoi/qui ? » (sans prép.). COI : « à/de qui ? ».
CC (temps, lieu, manière) : déplaçable / supprimable.
Subordonnée relative : qui, que, dont, où (complète un nom).

📝 Méthodes

Analyse de texte : réponds en phrases complètes, cite le texte (« … »), nomme les procédés et explique leur effet.
Réécriture : repère ce qui change (temps, personne, nombre) et accorde tout ce qui en dépend, puis relis.
Rédaction — imagination : respecte les consignes, structure (situation → péripéties → fin), décris. Réflexion : intro (problématique) → 2-3 arguments + exemples → conclusion. Garde 5 min pour te relire.

📚 Les œuvres (culture)

Autobiographie : écrire sur sa propre vie (« je »), pacte de sincérité.
Nouvelle / satire (« Le Credo », Sternberg) : récit court à chute, ironie sur la consommation.
Poésie : du lyrisme (sentiments) à l'engagement (défendre une cause).
Tragédie grecque : terreur & pitié, fatalité ; Œdipe, les Labdacides.
Antigone (Anouilh) : loi de l'État (Créon) contre la conscience (Antigone).
Le Joueur d'échecs (Zweig) : isolement, folie, dénonciation du totalitarisme.
