Comment lire le résultat

  1. Liste de cours qui s'affiche : tout va bien, on peut construire dessus.
  2. Erreur 403 access_denied ou "admin" : l'établissement bloque les applications tierces. Il faut demander l'autorisation ou changer de plan.
  3. Liste vide : l'accès marche mais tu n'es inscrit à aucun cours Classroom. Le problème est ailleurs.
  4. Cours visibles mais pièces jointes illisibles : Classroom passe, Drive non. On peut encore lire les annonces, pas les PDF.
