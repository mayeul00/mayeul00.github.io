Les notions et définitions clés à connaître

🧬 Génétique

Phénotype : ensemble des caractères observables.
Génotype : ensemble des allèles ; il détermine le phénotype.
Caryotype humain : 23 paires = 46 chromosomes (XX / XY).
ADN : molécule des chromosomes, porte l'information.
Gène : portion d'ADN déterminant un caractère. Allèle : version d'un gène.
Mutation : modification rare de l'ADN (germinale = héréditaire).
Environnement : peut modifier le phénotype (bronzage), mais ce n'est pas héréditaire.

🦠 Immunité

Barrières : peau & muqueuses.
Contamination = entrée ; infection = multiplication.
Phagocytose (rapide, non spécifique) : adhésion → absorption → digestion → rejet.
Lymphocytes B → anticorps (contre les antigènes).
Lymphocytes T → détruisent les cellules infectées par un virus.
Antigène : molécule du microbe reconnue par le système immunitaire.

🦋 Évolution

Parenté : + de caractères communs = + proche (ancêtre commun).
Sélection naturelle : le milieu favorise les mieux adaptés, qui se reproduisent + et transmettent leurs caractères.
Biodiversité : diversité du vivant. Crise : extinction massive (dinosaures ≈ 66 Ma).
L'Homme : primate, dans l'arbre de l'évolution.

🌍 La Terre & les risques

Plaques : la surface est faite de plaques mobiles. Séismes/volcans aux frontières.
Aléa : phénomène dangereux. Enjeu : ce qui peut être touché. Risque = aléa × enjeux.
Prévision (surveiller, alerter) + prévention (constructions, évacuation).
Au brevet : appuie toujours tes réponses sur les documents et explique le raisonnement (cause → conséquence).
