Mémo Brevet — Technologie

Notions clés à connaître

⚙️ Objet technique & chaînes

Fonction d'usage : le service rendu (à quoi sert l'objet).
Fonction technique : rôle d'une partie de l'objet.
Contrainte : limite (coût, sécurité, taille, environnement).
Chaîne d'énergie : alimenter → distribuer → convertir → transmettre.
Chaîne d'information : acquérir → traiter → communiquer.

📡 Capteurs & programmation

Capteur : entrée, mesure une grandeur (lumière, température).
Actionneur : sortie, produit un effet (moteur, LED, buzzer).
Carte programmable : Arduino, micro:bit (traite & commande).
Algorithme : suite d'instructions. Algorigramme : sa représentation.
Structures : séquence, condition (si…alors…sinon), boucle, variable.
Objet connecté / IoT : échange des infos via un réseau.

🌐 Réseaux

Switch : relie les machines d'un réseau local.
Routeur : relie des réseaux entre eux (et à Internet).
Serveur : fournit des ressources aux clients.
Adresse IP : numéro unique d'un appareil.
Protocole : règles de communication (paquets de données).
Web ≠ Internet : le Web est un service d'Internet.

♻️ Cycle de vie & dév. durable

Cycle de vie : extraction → fabrication → transport → utilisation → fin de vie.
Écoconception : réduire l'impact dès la conception.
Les 4 R : réduire, réutiliser, réparer, recycler.
Au brevet (sciences) : l'épreuve porte sur 2 disciplines (ici SVT + Techno), 1h. Lis bien les documents et justifie.
