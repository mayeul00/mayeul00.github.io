Mémo Brevet — Mathématiques

Toutes les formules et propriétés à connaître · DNB 3ᵉ · à relire avant l'épreuve

1 · Nombres & calculs

Priorités : parenthèses → puissances → ×/÷ → +/− (de gauche à droite).
Fractions : a/b + c/d → même dénominateur. a/b × c/d = (a×c)/(b×d). Diviser = multiplier par l'inverse : a/b ÷ c/d = a/b × d/c.
Puissances : aⁿ × aᵐ = an+m · aⁿ ÷ aᵐ = an−m · (aⁿ)ᵐ = an×m · a⁻ⁿ = 1/aⁿ · a⁰ = 1.
Notation scientifique : a × 10ⁿ avec 1 ≤ a < 10. Ex : 32 000 = 3,2 × 10⁴.
PGCD : plus grand diviseur commun. Une fraction est irréductible quand on a divisé numérateur et dénominateur par leur PGCD.
Nombre premier : exactement 2 diviseurs (1 et lui-même) : 2, 3, 5, 7, 11, 13…

2 · Calcul littéral

Développer (simple) : k(a + b) = ka + kb
Double distributivité : (a + b)(c + d) = ac + ad + bc + bd
Factoriser : trouver un facteur commun. ka + kb = k(a + b)
Réduire : regrouper les termes semblables (ex : 3x + 5x = 8x).
Équation : on fait la même opération des deux côtés du « = ». But : isoler x. Ex : 2x + 3 = 11 → 2x = 8 → x = 4.

3 · Proportionnalité, pourcentages, vitesse

Produit en croix : si a/b = c/d alors a × d = b × c (4ᵉ proportionnelle).
Pourcentage : t % de N = N × t/100. Augmenter de 20 % : ×1,2. Baisser de 20 % : ×0,8.
Vitesse : v = d / t · d = v × t · t = d / v. (Attention aux unités : km/h, m/s.)
Échelle = distance sur le plan / distance réelle (même unité).

4 · Fonctions

Fonction linéaire : f(x) = a x (proportionnalité). a = coefficient directeur. Droite passant par l'origine.
Fonction affine : f(x) = a x + b. a = coef. directeur (pente), b = ordonnée à l'origine. Droite.
Image / antécédent : l'image de x est f(x) ; un antécédent de y est un x tel que f(x) = y.
Coefficient directeur : a = (y₂ − y₁) / (x₂ − x₁).

5 · Théorème de Pythagore triangle rectangle

Théorème : si un triangle ABC est rectangle en A, alors BC² = AB² + AC² (BC = hypoténuse, le plus long côté, face à l'angle droit).
➤ Pour calculer une longueur :
1. Repérer l'angle droit et l'hypoténuse. 2. Écrire l'égalité de Pythagore. 3. Remplacer par les valeurs connues. 4. Isoler le côté cherché (utiliser √ si besoin).
Ex. ABC rectangle en A, AB = 3, AC = 4. BC² = 3² + 4² = 9 + 16 = 25, donc BC = √25 = 5.
➤ Réciproque (prouver qu'un triangle est rectangle) : on calcule séparément le plus grand côté au carré, et la somme des carrés des deux autres. S'ils sont égaux, le triangle est rectangle (angle droit face au plus grand côté). Sinon, il ne l'est pas (contraposée).

6 · Théorème de Thalès droites parallèles

Configuration : deux droites sécantes en A, coupées par deux droites parallèles (triangles « emboîtés » ou « papillon »). Points B, M sur une droite ; C, N sur l'autre, avec (MN) ∥ (BC).
Théorème : si (MN) ∥ (BC) alors AM/AB = AN/AC = MN/BC (rapports égaux).
➤ Pour calculer une longueur : 1. Vérifier la configuration (parallèles). 2. Écrire les 3 rapports égaux. 3. Garder les deux rapports utiles. 4. Produit en croix.
Ex. AM = 2, AB = 6, AN = 3. Alors AM/AB = AN/AC → 2/6 = 3/AC → AC = (6×3)/2 = 9.
➤ Réciproque (prouver que deux droites sont parallèles) : si AM/AB = AN/AC ET si les points sont alignés dans le même ordre, alors (MN) ∥ (BC).

7 · Trigonométrie triangle rectangle

Dans un triangle rectangle, pour un angle aigu : on repère le côté adjacent (à côté de l'angle), le côté opposé (face à l'angle) et l'hypoténuse.
SOH · CAH · TOA : cos = adjacent / hypoténuse sin = opposé / hypoténuse tan = opposé / adjacent
➤ Pour trouver un côté : choisir la formule (cos, sin ou tan) qui relie l'angle connu, le côté connu et le côté cherché, puis isoler.
➤ Pour trouver un angle : calculer le rapport, puis utiliser la touche inverse : angle = cos⁻¹(…) (ou sin⁻¹, tan⁻¹).
Ex. Angle de 30°, hypoténuse = 10, côté opposé = ? → sin(30°) = opp/10 → opp = 10 × sin(30°) = 10 × 0,5 = 5.

8 · Transformations

Translation : glissement (direction, sens, longueur). Conserve longueurs, angles, aires.
Rotation : autour d'un centre, d'un angle donné, dans un sens. Conserve longueurs et aires.
Symétrie axiale (par rapport à une droite) ; symétrie centrale (par rapport à un point).
Homothétie de rapport k : agrandit (k > 1) ou réduit (0 < k < 1). Les longueurs sont ×|k|, les aires ×k².

9 · Aires & volumes

Aires : rectangle L×l · triangle (b×h)/2 · disque π × r² · parallélogramme b×h.
Périmètre du cercle : 2 × π × r.
Volumes : pavé L×l×h · cube c³ · cylindre π × r² × h.
Volumes (suite) : prisme = aire base × h · pyramide / cône = ⅓ × aire base × h · sphère (4/3) × π × r³.
Agrandissement / réduction de rapport k : longueurs ×k, aires ×k², volumes ×k³.
Conversions : 1 L = 1 dm³ · 1 m³ = 1000 L.

10 · Statistiques & probabilités

Moyenne = somme des valeurs / nombre de valeurs (pondérée si effectifs).
Médiane : valeur qui partage la série (ordonnée) en deux moitiés.
Étendue = valeur max − valeur min.
Probabilité = nb de cas favorables / nb de cas possibles (entre 0 et 1).
Événement contraire : P(contraire) = 1 − P(A).
Deux épreuves (arbre) : on multiplie les probabilités le long des branches.

11 · Algorithmique (Scratch)

Variable : mémorise une valeur. Boucle : répète des instructions. Condition (si… alors… sinon).
Lire un programme : suivre les instructions dans l'ordre, suivre la valeur des variables étape par étape.
